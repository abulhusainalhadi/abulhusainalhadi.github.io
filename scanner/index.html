Teks dikenal pasti (OCR)

Tiada teks dikesan. Cuba penapis "Hitam Putih" atau "Ajaib", atau gambar yang lebih jelas.

Tetapan

OCR (kenal pasti teks)

Teks dimasukkan ke dalam PDF (boleh dicari & disalin) dan boleh dilihat melalui butang Aa Teks. OCR dibuat dalam telefon; kali pertama perlu internet untuk memuat data bahasa (~4 MB). Untuk tulisan tangan, hidupkan "Salinan Google Docs" di bawah — OCR Google lebih baik untuk tulisan tangan.

Format lalai

Untuk menukar fail PDF sedia ada kepada JPG: tekan Galeri, pilih fail PDF, kemudian pilih format JPG dan tekan Simpan.

Google Drive

Cara dapatkan Client ID (sekali sahaja)
  1. Buka Google Cloud Console → Google Drive API dan tekan Enable (boleh guna projek sedia ada).
  2. Pergi ke APIs & Services → OAuth consent screen. Jika belum ada, pilih External, isi nama app, dan tambah emel anda sebagai Test user.
  3. Pergi ke Credentials → Create credentials → OAuth client ID, jenis Web application.
