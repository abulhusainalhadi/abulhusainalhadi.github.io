# Sync Drive Peribadi

Alat ini digunakan secara peribadi oleh Abul Husain Al-Hadi bin Sa'ari untuk menyelaraskan (sync) fail kerja antara akaun Google Drive dan OneDrive miliknya sendiri, menggunakan perisian sumber terbuka rclone.

This is a personal tool used only by its owner to synchronise his own work files between his own Google Drive and OneDrive accounts using rclone. It is not offered to the public.
